## Run B：跨机 a2a 冒烟（唯一剩余项）

重新提交同一个启动脚本，作业环境变量只改两个：

```
FORCE_EP=4  RUN_TAG=glm16_ep_smoke_xnode
```

FORCE_EP 由入口脚本在计划生成后把 `--expert-model-parallel-size` 覆写为 4
（tp4×ep4=16 > 8 卡/节点 → EP 组跨节点，dp=4 恰被 ep=4 整除，合法）。
走环境变量而不是手改生成文件：重提交会重新生成计划，手改会被覆盖。
成功判据同上；若跨机 a2a 有问题会在此暴露（hang 或 RCCL 报错，
DIST_TIMEOUT_MIN 默认 30 分钟兜底出栈）。
